# Workflow — Adding a new skill

Grow the shared skills library. **This edits the shared `.agents/` blueprint — do it only when working on the blueprint repository itself, not during normal project work** ([blueprint README](../README.md)).

Follow [skill-authoring](../skills/skill-authoring/SKILL.md): confirm no existing skill covers it (or extend that one) → copy [`_template`](../skills/_template/SKILL.md) → write every section with real steps → register in [SKILLS.md](../docs/SKILLS.md) → add a routing row in the project [AGENTS.md](../../AGENTS.md) if it's a common task (approval required) → validate links both ways.
